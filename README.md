# Filemanager

Персональный файловый менеджер Windows. **Целевой стек: Rust + GPUI.** Своя реализация UX по мотивам Atlas; ни исходники, ни элементы оформления Atlas не используются.

> **Статус: экспериментальная Windows-альфа. Сборка №2 успешно прошла тесты ядра и компиляцию GPUI, но новую функциональность рабочей ветки после этого ещё не собирали и визуально не проверяли.** Не используйте приложение для единственной копии важных документов до ручной проверки. Основная разработка: ветка `feat/native-gpui-foundation`.

## Что уже в коде

| Направление | Реализовано в коде | Что остаётся |
|---|---|---|
| 1. Нативный интерфейс | GPUI-окно, вкладки, две панели, Miller Columns / список, сохранение рабочих пространств; правый клик открывает контекстные действия, внутренний drag-and-drop в Drop Zone | Виртуальные списки, полноценный Windows drag-and-drop, полировка тем/анимаций/горячих клавиш |
| 2. Операции | Копирование файлов и вложенных папок во временную область с публикацией без перезаписи; создание папок, переименование/Undo в GUI, Drop Zone, очередь, отмена и байтовый прогресс, системная Корзина | Полноценные переносы между дисками, штатный интерфейс очереди с ошибками, устойчивое возобновление после аварии, массовые операции |
| 3. Поиск и предпросмотр | Строка поиска GPUI с Ctrl+F и русскими именами; **постоянный SQLite-индекс** до 100 000 путей на папку, фоновая подготовка и кнопка Refresh index; ограниченный просмотр текста/метаданных | Автоматическое обновление индекса (USN/notify), виртуальные результаты, PDF/Office/изображения/видео |
| История файлов | SQLite, отслеживание изменений из сторонних программ, дата/время, учётная запись наблюдателя и редактируемые поля фактического автора и комментария в GUI | Наблюдение при закрытом окне, идентификация реального автора на общих дисках, обработка сетевых уведомлений |

**Категорически не сохраняем старые содержимые файлов, дельты, резервные копии или бинарные версии.** Только метаданные изменений и введённые комментарии. История не позволяет восстановить содержимое старой версии.

## Структура

- `crates/core` — независимое от интерфейса ядро: вкладки/папки, операции, история SQLite, поиск и предпросмотр.
- `crates/desktop` — нативное окно Windows на GPUI.
- `crates/cli` — `fmctl`, минимальная утилита для проверки движка и редактирования комментариев.
- `filemanager/` и `tests/` — ранний **Python-прототип**, не является целевым приложением. Не дорабатываем его вместо Rust.

## Текущий этап разработки (9 октября 2026)

- В рабочей ветке добавлен переключатель обычного списка и Miller Columns.
- Добавлены кнопки Forward, Focus pane, Close tab и отключение наблюдения.
- Drop Zone направляет копирования через последовательную очередь операций; папки и файлы копируются через временную область в конечном каталоге, с проверками до публикации.
- Windows-переносы используют `MoveFileW`, который отказывается перезаписывать существующую цель.
- GPUI привязан к совместимой паре опубликованных пакетов `gpui-ce 0.2.2` + `gpui_ce_platform 0.1.0`.
- 9 октября [ручная Windows-сборка №2](https://github.com/Aev199/filemanager/actions/runs/37959476963) **успешна** (тесты, сборка и упаковка). Следующие изменения **ещё не проверялись компилятором**; рабочая ветка остаётся draft PR.

## Новое в следующей альфе (ещё не собрано)

- **Контекстное меню по правой кнопке**: Open, Stage to Drop Zone, Rename,
  Copy full path, Recycle.
- **Создание папки**, переименование через последовательную очередь, Undo
  последнего переименования с отказом при конфликте.
- **Drag-and-drop внутри GPUI**: перетащить папку или файл на Drop Zone.
  Отпускание мыши не запускает перенос и не удаляет исходный файл.
- **Папки копируются целиком**: вложенные каталоги, файлы, пустые папки.
  Данные сначала готовятся во временной папке на том же диске назначения,
  затем готовый результат публикуется без перезаписи. SymLink и Windows
  junction/reparse points запрещены, чтобы не уйти за границы исходной папки.
- **Отмена** кооперативная, между блоками по 256 КБ и между файлами.
  Уже опубликованные результаты предыдущих заданий остаются; недокопированный
  файл/каталог с целевым именем не публикуется.
- **Прогресс** в MiB в строке состояния, без тяжёлых операций в UI.
- Имеются защитные тесты на отмену, конфликты путей и копирование каталогов.
  Выполнение этих тестов на последнем коде и сборка Windows EXE **ещё не
  подтверждены**. Перед ручным тестированием важными файлами использовать
  нельзя.

## Текущий этап поиска (после первой зелёной сборки)

- Новый модуль `crates/core/src/persistent_index.rs` хранит **только имена и
  пути файлов** в `%LOCALAPPDATA%\\Filemanager\\file-index.sqlite3`.
  Содержимое файлов не индексируется и не копируется.
- Первая индексация папки выполняется в фоне; при следующих поисках
  повторный обход каталога не требуется. Для обновления служит
  кнопка **Refresh index**. Индексы выбранных корневых папок независимы.
- Обновление атомарное: если сканирование не удалось из-за предела записей,
  предыдущий индекс остаётся в базе. При отказе доступа отдельные папки
  могут быть пропущены — интерфейс показывает предупреждение.
- Исправлена проверка Undo: отмена переименования направляется через очередь
  и отказывается работать, если файл назначения изменился.
- **Последние изменения пока не проходили Windows CI**; успешная сборка
  №2 относится к более раннему состоянию кода.

## Дополнительная работа после первой успешной сборки

- Копирование публикует только целый файл; при неудаче временный файл
  удаляется обычным завершением операции. Защита от перезаписи остаётся.
- Копирование проверяет изменение исходного файла во время операции и
  по возможности сохраняет атрибуты доступа и время изменения.
- **Очередь запоминает состояние источника при постановке задачи.** Если
  файл или папка изменились перед выполнением, операция отклоняется.
  При отправке в Корзину первое нажатие готовит именно это задание,
  а второе подтверждает его. Это защита от ряда гонок, но не
  абсолютная гарантия идентичности файла на уровне файловых дескрипторов.
- Добавлены right-click меню, перетаскивание файлов/папок **внутри GPUI** в Drop Zone, создание папки и Rename с Undo. Перенос выполняется только после отдельной команды, а не при отпускании мыши.
- Для папок с большим числом файлов в GPUI появилась команда **Show more** (порциями по 200, временное ограничение 3000 до виртуального списка).
- Поиск по именам текущей папки и подпапок сохраняет индекс в SQLite. Первый обход выполняется в фоне, следующие запросы используют уже сохранённую базу; есть `Refresh index`. Поддерживаются русские имена, Ctrl+F и кликабельные результаты.
- Добавлено сохранение рабочего пространства `Default` в SQLite без
  копирования данных файлов; отсутствующие папки при восстановлении пропускаются.
- Добавлены настоящие редактируемые поля автора и комментария к отдельному событию истории прямо в GPUI; при выборе записи загружается её текущий текст.
- На время копирования запрещены повторные старты; новые элементы Drop Zone
  не теряются, показывается первая ошибка. Копирование можно отменить, в статусе
  отображается переданный объём. На диске могут остаться временные следы после
  аварийного закрытия; они не являются историей версий.
- Новая сборка **не запускалась автоматически**: не тратим минуты GitHub Actions.

## Дополнение: поиск и редактор истории

- В поисковой строке набери часть имени файла. Индекс активной папки
  и вложенных каталогов впервые создаётся в фоне и остаётся в SQLite;
  последующий поиск использует сохранённые пути. Есть кнопки **Refresh index**
  для актуализации и **Close results**. Файлы с русскими именами учитываются.
  Пока обновление индекса **не автоматическое**: после создания/переименования
  файлов в других программах нужно нажать Refresh index. Ограничение —
  100 тысяч путей на выбранную папку. Сканирование недоступных подпапок
  может дать неполные результаты.
- Для комментария теперь не нужен буфер обмена. Выдели файл,
  справа выбери конкретную запись истории, затем введи автора (если известен)
  и комментарий. Сохранение относится именно к выбранному событию.
  **Имя автора, введённое вручную, не считается автоматически проверенным.**
- История наблюдения остаётся **только метаданными**, старые версии файла
  не хранятся, содержимое из прошлых сохранений восстановить невозможно.
- Эти изменения сделаны **после** успешной CI-сборки №2. Пока не
  выполнен новый ручной запуск, считать текущую ветку проверенной сборкой
  нельзя.

## Как пользоваться экспериментальным GUI

- Щёлкни папку в колонке для перехода, файл — для выделения, `Open` — открыть обычной программой Windows.
- `+` добавляет вкладку, `Split` показывает вторую панель. `Mode` переключает список и Miller Columns. `Save layout` сохраняет открытые вкладки, панели и режим, а `Restore layout` возвращает их. Сохранённый вариант Default загружается при новом запуске.
- `Stage` добавляет выбранный файл или папку в Drop Zone. Можно перетащить элемент из списка мышью на Drop Zone (только внутри программы). Перейди в папку назначения и нажми `Copy here`; существующие имена **не заменяются**. Кнопка `Cancel copy` отменяет текущую задачу.
- `New folder` создаёт папку после ввода имени через проверяемую очередь. Правая кнопка мыши открывает меню действий, включая `Rename`; после переименования доступно `Undo last rename`. `Recycle` требует повторного подтверждения и отправляет элемент в системную Корзину, **не навсегда**.
- `Watch folder` начинает наблюдать за активной папкой, в том числе за изменениями в сторонних программах. Выдели файл — увидишь его историю справа; `Refresh` обновляет отображение.
- История хранится в `%LOCALAPPDATA%\Filemanager\native-history.sqlite3`; состояние окна — в `workspaces.sqlite3`. Пока приложение закрыто, наблюдение не работает. Выдели файл, выбери событие кнопкой `Select this save`, введи автора и комментарий справа и нажми `Save comment`. В отличие от Git, старые копии файлов не сохраняются.

Сочетания: `Ctrl+T` новая вкладка, `Ctrl+F` поиск, `Alt+Left` назад, `Alt+Up` вверх, `F5` обновить, `Ctrl+Shift+S` в Drop Zone.

## Комментарии, поиск и другие операции до появления GUI

В терминале с Rust:

```powershell
cargo run -p filemanager-cli -- history "C:\WORK\model.xlsx"
cargo run -p filemanager-cli -- comment 3 "Инженер" "Уточнена жёсткость свай"
cargo run -p filemanager-cli -- search "C:\WORK" "fundam"
cargo run -p filemanager-cli -- preview "C:\WORK\note.txt"
cargo run -p filemanager-cli -- watch "C:\WORK"
```

Утилита также имеет команды `copy` (файлы и папки), `move`, `rename`, `mkdir PARENT NAME`, `trash FILE --confirm`. Для них требуется явный запуск человеком. Операции не перезаписывают файлы с существующими именами, при нештатной ситуации возвращают ошибку.

**Что важно знать:** время в истории — момент обнаружения; не всегда точная секунда Ctrl+S. Имя пользователя — учётная запись, под которой работает наблюдатель, **не гарантированное имя автора документа**. Реального автора можно записать вручную в поле `author`. Файловое отслеживание на сетевых дисках зависит от того, какие уведомления отдаёт Windows/сервер.

# Filemanager

Персональный файловый менеджер Windows. **Целевой стек: Rust + GPUI.** Своя реализация UX по мотивам Atlas; ни исходники, ни элементы оформления Atlas не используются.

> **Статус: исходный код экспериментальной Windows-альфы. Компиляция Windows EXE и визуальное тестирование в этом окружении пока не выполнялись.** Не используйте приложение для единственной копии важных документов до ручной проверки. Основная разработка: ветка `feat/native-gpui-foundation`.

## Что уже в коде

| Направление | Реализовано в коде | Что остаётся |
|---|---|---|
| 1. Нативный интерфейс | GPUI-окно, вкладки, 2 панели, колоночная навигация, места Home/Documents/Downloads/Desktop, выбор/открытие файлов | Полная полировка UX, контекстное меню, виртуальные списки, удобные клавиатурные операции, настоящее перетаскивание |
| 2. Операции | Без перезаписи существующих файлов; файловое копирование в фоне, системная Корзина с подтверждением, Drop Zone; в ядре также move/rename/undo | Копирование директорий, все операции через UI, отмена при длинных задачах, очередь с обработкой ошибок, отменой и восстановлением после сбоя, прогресс по байтам |
| 3. Поиск и предпросмотр | Поиск по имени (ядро и CLI), ограниченный индекс папки, bounded preview текста и метаданные большинства остальных форматов | Поле поиска в GUI, постоянный индекс + инкрементальные обновления, рендер PDF/Office/изображений и пакетные операции |
| История файлов | SQLite, уведомления об изменениях сторонними приложениями, отметка времени, учётная запись наблюдателя, автор и комментарий | Ввод комментария прямо в GUI, фон при закрытом приложении, аудит реального автора на общих дисках |

**Категорически не сохраняем старые содержимые файлов, дельты, резервные копии или бинарные версии.** Только метаданные изменений и введённые комментарии. История не позволяет восстановить содержимое старой версии.

## Структура

- `crates/core` — независимое от интерфейса ядро: вкладки/папки, операции, история SQLite, поиск и предпросмотр.
- `crates/desktop` — нативное окно Windows на GPUI.
- `crates/cli` — `fmctl`, минимальная утилита для проверки движка и редактирования комментариев.
- `filemanager/` и `tests/` — ранний **Python-прототип**, не является целевым приложением. Не дорабатываем его вместо Rust.

## Проверка на Windows

На машине для разработки с Rust и Windows C++ Build Tools:

```powershell
cargo test -p filemanager-core
cargo run -p filemanager-desktop
```

Если Rust на компьютере устанавливать нельзя, добавлен **ручной** GitHub Actions workflow `.github/workflows/windows-portable.yml`. Он запускается только через **Actions → Windows portable EXE (manual) → Run workflow** для этой ветки. При успешном прохождении тестов и сборки появится ZIP-артефакт `filemanager-windows`, внутри `filemanager-desktop.exe`. **Автоматических сборок по push нет**, чтобы не тратить лимит бесплатного GitHub. ## Как пользоваться экспериментальным GUI

- Щёлкни папку в колонке для перехода, файл — для выделения, `Open` — открыть обычной программой Windows.
- `+` добавляет вкладку, `Split` показывает вторую панель.
- `Stage` добавляет выбранный файл в Drop Zone. Перейди в папку назначения и нажми `Copy here`; существующие имена **не заменяются**.
- `Recycle` требует повторного нажатия. Удаление идёт в системную Корзину, **не навсегда**.
- `Watch folder` начинает наблюдать за активной папкой, в том числе за изменениями в сторонних программах. Выдели файл — увидишь его историю справа; `Refresh` обновляет отображение.
- История хранится в `%LOCALAPPDATA%\Filemanager\native-history.sqlite3`. Пока приложение закрыто, его наблюдатель не работает.

Сочетания: `Ctrl+T` новая вкладка, `Alt+Left` назад, `Alt+Up` вверх, `F5` обновить, `Ctrl+Shift+S` в Drop Zone.

## Комментарии, поиск и другие операции до появления GUI

В терминале с Rust:

```powershell
cargo run -p filemanager-cli -- history "C:\WORK\model.xlsx"
cargo run -p filemanager-cli -- comment 3 "Инженер" "Уточнена жёсткость свай"
cargo run -p filemanager-cli -- search "C:\WORK" "fundam"
cargo run -p filemanager-cli -- preview "C:\WORK\note.txt"
cargo run -p filemanager-cli -- watch "C:\WORK"
```

Утилита также имеет команды `copy`, `move`, `rename`, `trash FILE --confirm`. Для них требуется явный запуск человеком. Операции не перезаписывают файлы с существующими именами, при нештатной ситуации возвращают ошибку.

**Что важно знать:** время в истории — момент обнаружения; не всегда точная секунда Ctrl+S. Имя пользователя — учётная запись, под которой работает наблюдатель, **не гарантированное имя автора документа**. Реального автора можно записать вручную в поле `author`. Файловое отслеживание на сетевых дисках зависит от того, какие уведомления отдаёт Windows/сервер.

## Приоритет следующих итераций

1. Получить зелёную Windows-сборку, проверить интерфейс мышью и клавиатурой.
2. Завершить UX этапа 1: полноразмерные списки, контекстное меню, горячие клавиши, изменение размеров колонок.
3. Довести этап 2: надёжные операции с папками, очередь с прогрессом и отменой, native drag & drop.
4. Довести этап 3: графическое поле быстрого поиска, индекс в фоне, графические превью PDF/изображений; добавить комментарии к истории в GUI.

Облачные диски, SFTP, FTP и плагины **исключены из объёма**.

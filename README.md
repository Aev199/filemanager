# Filemanager

Персональный файловый менеджер Windows. **Целевой стек: Rust + GPUI.** Своя реализация UX по мотивам Atlas; ни исходники, ни элементы оформления Atlas не используются.

> **Статус: экспериментальная Windows-альфа. Сборка №2 успешно прошла тесты ядра и компиляцию GPUI, но новую функциональность рабочей ветки после этого ещё не собирали и визуально не проверяли.** Не используйте приложение для единственной копии важных документов до ручной проверки. Основная разработка: ветка `feat/native-gpui-foundation`.

## Что уже в коде

| Направление | Реализовано в коде | Что остаётся |
|---|---|---|
| 1. Нативный интерфейс | GPUI-окно, вкладки, 2 панели, Miller Columns / список, навигация, восстановление сохранённой конфигурации вкладок и панелей | Полная полировка UX, контекстное меню, виртуальные списки, удобные клавиатурные операции, настоящее перетаскивание |
| 2. Операции | Копирование файлов через временный файл с публикацией без перезаписи, сохранение времени изменения, очередь, системная Корзина, Drop Zone; move/rename/undo в ядре | Копирование директорий, все операции через UI, отмена при длинных задачах, очередь с обработкой ошибок, отменой и восстановлением после сбоя, прогресс по байтам |
| 3. Поиск и предпросмотр | Поиск по имени (ядро и CLI), ограниченный индекс папки, bounded preview текста и метаданные большинства остальных форматов | Поле поиска в GUI, постоянный индекс + инкрементальные обновления, рендер PDF/Office/изображений и пакетные операции |
| История файлов | SQLite, мониторинг внешних сохранений, время, учётная запись наблюдателя, автор и комментарий; временно можно вставить комментарий из буфера обмена прямо в GUI | Нормальное редактируемое поле комментария, фоновый монитор при закрытом окне, проверка реального автора на общих дисках |

**Категорически не сохраняем старые содержимые файлов, дельты, резервные копии или бинарные версии.** Только метаданные изменений и введённые комментарии. История не позволяет восстановить содержимое старой версии.

## Структура

- `crates/core` — независимое от интерфейса ядро: вкладки/папки, операции, история SQLite, поиск и предпросмотр.
- `crates/desktop` — нативное окно Windows на GPUI.
- `crates/cli` — `fmctl`, минимальная утилита для проверки движка и редактирования комментариев.
- `filemanager/` и `tests/` — ранний **Python-прототип**, не является целевым приложением. Не дорабатываем его вместо Rust.

## Дополнительная работа после первой успешной сборки

- Копирование публикует только целый файл; при неудаче временный файл
  удаляется обычным завершением операции. Защита от перезаписи остаётся.
- Копирование проверяет изменение исходного файла во время операции и
  по возможности сохраняет атрибуты доступа и время изменения.
- Добавлено сохранение рабочего пространства `Default` в SQLite без
  копирования данных файлов; отсутствующие папки при восстановлении пропускаются.
- Появилась запись комментариев из буфера Windows в журнал конкретных
  сохранений, без стирания вручную указанного автора.
- На время копирования запрещены повторные старты; новые элементы Drop Zone
  не теряются, показывается первая ошибка.
- Новая сборка **не запускалась автоматически**: не тратим минуты GitHub Actions.

## Как пользоваться экспериментальным GUI

- Щёлкни папку в колонке для перехода, файл — для выделения, `Open` — открыть обычной программой Windows.
- `+` добавляет вкладку, `Split` показывает вторую панель. `Mode` переключает список и Miller Columns. `Save layout` сохраняет открытые вкладки, панели и режим, а `Restore layout` возвращает их. Сохранённый вариант Default загружается при новом запуске.
- `Stage` добавляет выбранный файл в Drop Zone. Перейди в папку назначения и нажми `Copy here`; существующие имена **не заменяются**.
- `Recycle` требует повторного нажатия. Удаление идёт в системную Корзину, **не навсегда**.
- `Watch folder` начинает наблюдать за активной папкой, в том числе за изменениями в сторонних программах. Выдели файл — увидишь его историю справа; `Refresh` обновляет отображение.
- История хранится в `%LOCALAPPDATA%\Filemanager\native-history.sqlite3`; состояние окна — в `workspaces.sqlite3`. Пока приложение закрыто, наблюдение не работает. Для комментария скопируй текст (Ctrl+C) и нажми `Paste comment` под нужной записью истории — это временный способ до появления удобного поля ввода.

Сочетания: `Ctrl+T` новая вкладка, `Alt+Left` назад, `Alt+Up` вверх, `F5` обновить, `Ctrl+Shift+S` в Drop Zone.

## Комментарии, поиск и другие операции до появления GUI

В терминале с Rust:

```powershell
cargo run -p filemanager-cli -- history "C:\WORK\model.xlsx"
cargo run -p filemanager-cli -- comment 3 "Инженер" "Уточнена жёсткость свай"
cargo run -p filemanager-cli -- search "C:\WORK" "fundam"
cargo run -p filemanager-cli -- preview "C:\WORK\note.txt"
cargo run -p filemanager-cli -- watch "C:\WORK"
```

Утилита также имеет команды `copy`, `move`, `rename`, `trash FILE --confirm`. Для них требуется явный запуск человеком. Операции не перезаписывают файлы с существующими именами, при нештатной ситуации возвращают ошибку.

**Что важно знать:** время в истории — момент обнаружения; не всегда точная секунда Ctrl+S. Имя пользователя — учётная запись, под которой работает наблюдатель, **не гарантированное имя автора документа**. Реального автора можно записать вручную в поле `author`. Файловое отслеживание на сетевых дисках зависит от того, какие уведомления отдаёт Windows/сервер.

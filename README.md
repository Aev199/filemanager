# Filemanager

Личный файловый менеджер для Windows. UX по мотивам Atlas, реализация собственная.

## Прототип (этап 1)

- Нативное окно Python/Tkinter: вкладки, навигация, фильтр по имени, открытие файлов внешними программами.
- Наблюдение за выбранной папкой, SQLite-журнал событий и комментарии.
- **Без копий файлов:** хранятся только путь, размер, время обнаружения изменения, имя учётной записи наблюдателя, введённые автор и комментарий.
- История не восстанавливает прежнее содержимое и не позволяет сравнивать версии.
- Файловые операции в первом прототипе только для чтения.

Запуск без дополнительных пакетов, нужен Python 3.10+:

```bat
python -m filemanager.app
```

Проверка:

```bat
python -m unittest discover -s tests -v
```

История: нажми **«Наблюдать за папкой…»**, выбери папку. Оставь окно открытым во время работы с Excel/Word/CAD. Выдели файл для просмотра событий и добавления комментария. SQLite находится в `%LOCALAPPDATA%\Filemanager\history.sqlite3`.

**Ограничения:** наблюдатель проверяет папку раз в 4 секунды, ограничение 50 000 файлов; закрытие окна останавливает наблюдение; быстрые промежуточные сохранения могут быть пропущены. «Обнаружен» — первая встреча файла, а не дата его создания. Учётная запись наблюдателя не доказывает реального авторства. Поле автора можно заполнить вручную. Без снимков файлов восстановление невозможно.

## Дорожная карта

1. Навигация и UX: Miller Columns, split panes, вкладки, клавиатура, sidebar.
2. Надёжные copy/move/delete/undo, drag & drop, Drop Zone.
3. Индексированный поиск, предпросмотр, пакетные операции, эффективные Windows-уведомления.

Облачные подключения и плагины не нужны. Прототип намеренно Python/Tkinter, чтобы проверить поведение на рабочем ПК без установки Rust. Целевой стек нативной оболочки после обкатки — Rust + GPUI. Это пока не полноценный Atlas.

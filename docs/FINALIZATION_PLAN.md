## Исправлено в ходе проверки

1. **Статус закрытого предпросмотра** (отложенный дефект пакета 4): если окно
   предпросмотра закрыто его крестиком или упало, менеджер в течение ~0,5 с
   показывает «Окно предпросмотра закрыто» / «…завершился с ошибкой…» и
   убирает кнопку «Закрыть предпросмотр». `PreviewProcess::exited()` +
   unit-тест.
2. **`\\?\` в путях**: предпросмотр массового переименования, выделение после
   операций и тексты сообщений показывали `\\?\C:\…`; на Windows это ломало
   тест и выделение нового файла. Пути нормализуются, сообщения очищаются.
3. **Палитра в английской раскладке**: `yfcnh` находит «Настройки», `dbl` —
   команды «Вид». Тест в `interface_policy`.
4. **Корзина при 8.3-путях** (найдено Windows CI): Shell сообщает длинные
   имена папок, поэтому путь вида `C:\Users\RUNNER~1\…` не совпадал и
   квитанция терялась — Undo удаления/замены/переноса становился недоступен.
5. **Undo замены отвергал собственную копию** (найдено Windows CI): копия
   публикуется под именем только что удалённого в Корзину файла, и NTFS
   «туннелирование» подставляет прежнее время создания. Снимок теперь
   переснимается после публикации; отличие допускается только во времени
   создания корневого элемента. Отказ Undo называет изменившееся свойство.
6. **`Σ/ς` в массовом переименовании** (найдено Windows CI): сравнение Windows
   их различает; теперь совпадение по Unicode-регистру тоже считается
   конфликтом (переименование ничего не заменяет, ложный конфликт безопасен).

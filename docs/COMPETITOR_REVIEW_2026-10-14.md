# Чего не хватает Papka — разбор других файловых менеджеров (14.10.2026)

Источники: форумы Directory Opus, Total Commander, XYplorer, AlternativeTo,
ElevenForum, Microsoft Q&A, техпресса. Оценки ценности — для инженеров на
сетевых DFS-дисках.

## Жалобы, которых нужно избегать

1. Зависание на недоступном сетевом диске — листинг асинхронно, с таймаутом
   и состоянием «диск недоступен».
2. Дорогие колонки и подсчёты на сети (15 с вместо 0,5 с у DOpus).
3. Общая медлительность (главная претензия к Files и Explorer Windows 11).
4. Перегруженный интерфейс и длинное контекстное меню.
5. Потеря настроек вида (ShellBags в Explorer).

## Рекомендуемые следующие шаги

1. Правила для сетевых путей: без блокировок, таймауты, без дорогих колонок.
2. Сравнение и синхронизация двух папок на базе безопасного копирования.
3. Размер папок по запросу/в фоне с кэшем.
4. Копирование путей (UNC/DFS, имя, ссылка) и «Недавние места».
5. Миниатюры и просмотр DWG без AutoCAD, просмотр по Space.

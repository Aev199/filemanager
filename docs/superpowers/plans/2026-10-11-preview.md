# Preview Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline. User authorized sequential work and working-branch push without questions.

**Goal:** Isolated document preview, bounded thumbnails and responsive inspector.
**Architecture:** Core preview_host owns child lifecycle; document_preview owns
Windows STA/window/handler; thumbnail validates cached/rendered pixels;
desktop inspector schedules bounded background requests.
**Tech Stack:** Rust/GPUI, existing windows/windows-sys/image dependencies.
**Spec:** docs/superpowers/specs/2026-10-11-preview-design.md

## Global Constraints

No stored historical contents; no document decoder dependency; read-only.
Documents <=64 MiB; child Job memory 256 MiB, kill-on-close.
Thumbnails edge 1..512, timeout 5s; PNG cache <=256/64 MiB.
One details worker and one thumbnail worker per window; no filesystem UI reads.

## Review Focus

- Handler hangs/crashes: manager remains usable and can kill owned child.
- Missing provider or initialization failure: release handles/COM/window and explain.
- Compressed image with huge dimensions: reject before allocation/decode.
- Rapid A/B/A selection: only latest generation displays; workers stay bounded.
- Cached corrupt PNG/concurrent writer: no unbounded decode or partial-cache publication.

# Сверка рабочего интерфейса с Atlas

Цель: приблизить существующий Windows Rust + GPUI интерфейс к рабочей геометрии
Atlas, сохранив навигацию, две панели, копирование и историю метаданных.
Пользователь поручил написать план и выполнить его без подтверждений.

Источники: https://atlasfm.modhyt.org/images/app-screenshot.png и ролики
https://atlasfm.modhyt.org/videos/{millercolumns,tabs-and-panes,drop-zone,
drag-and-drop-navigation,fast-fuzzyfinder,filter-by-typing}.mp4.
Изучены выборки кадров, не запущено само приложение Atlas.
Скриншот и видео показывают разные темы иконок; единственную тему не копируем.

## Требования

- Miller: не обрезать цепочку искусственным максимумом из трёх колонок.
  Все предки доступны горизонтальной прокруткой. Колонки меняют ширину независимо,
  увеличивая ширину содержимого; фиксированная сумма split-group здесь не подходит.
  Предки 144 px, текущая минимум 200 px, preview 160 px. Свободная ширина
  достаётся текущей колонке; при переполнении прокручивается цепочка.
  Ручные размеры 144/200/160..4000 px; Esc во время resize возвращает исходные.
  В узкой панели preview можно убрать, но текущую папку не скрывать.
- При изменении пути/вкладки/preview/ширины показать текущую колонку.
  Использовать реальные bounds после layout, включая пользовательский resize.
  Обычные notify не должны сбрасывать ручную горизонтальную прокрутку.
  Preview показывается рядом с текущей колонкой, когда оба помещаются.
- Строки файлов и результатов поиска 24 px, заголовки колонок 24 px.
  Выбранные строки имеют яркую синюю заливку и контрастный белый текст
  в обеих темах; путь в колонках заметнее hover, но слабее активного выделения.
- Различать selected, trail, hover и неактивное выделение. Неактивное
  выделение остаётся узнаваемым. Убрать скругление отдельной строки файла.
- Не менять механизм копирования, журнал без копий файлов, сохранённые
  настройки, type-ahead, filter, two-pane session и модальные ограничения.
- Инспектор остаётся доступен по Ctrl+I; компактная зона переноса сохраняется.

## Границы

Облака/FTP/плагины исключены исходным соглашением. Произвольный tiling трёх
и более областей — отдельный архитектурный этап, не часть этой доработки.
Linux check и чистые policy-тесты не заменяют Windows screenshots/smoke.
Новый интерфейс не считать визуально принятым без реального Windows снимка.

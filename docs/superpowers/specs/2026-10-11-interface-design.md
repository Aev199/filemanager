# Пакет 5 — интерфейс

Цель: повседневная навигация мышью и клавиатурой, без новых файловых механизмов.
User authorized sequential native execution without approval prompts.

1. Закреплённая вкладка сохраняет положение и остаётся обычной навигационной
вкладкой. Ctrl+W, средняя кнопка, крестик и «закрыть другие» её не закрывают.
Снять закрепление можно через контекстное меню. Порядок не меняем автоматически;
перетаскивание по-прежнему доступно. Закрепление сохраняется в workspace SQLite,
старые базы мигрируют с default false; недоступные папки пропускаются как раньше.
2. Ctrl+K и кнопка открывают палитру: русский поиск по словам, список существующих
команд, стрелки/Enter/Escape, disabled для недопустимых действий. Никаких новых
путей исполнения файловых операций. Модальные диалоги не перекрываем палитрой.
3. Настройки: светлая/тёмная тема, скрытые файлы, боковая панель, инспектор.
Черновые значения применяются после успешного фонового SQLite save; ошибка
остаётся в диалоге. Отмена не меняет настройки. Значения восстанавливаются при
старте; существующий session layout хранится отдельно. Не меняем shell/theme ОС.
4. Рамка: только в текущей папке обычных файловых списков/колонок любой панели;
колонку предка сначала активируют обычным кликом. Рамка начинается с пустого места
(включая узкий правый отступ), не перехватывает drag файлов. Пересекающиеся строки
выбираются в видимом порядке; Ctrl добавляет к исходному выбору. Снимок списка,
сортировка, фильтр, вкладка или навигация изменились — отмена жеста, не выбор
нового дерева. Escape возвращает начальный выбор. Прокрутка во время жеста
отменяет его; автоматическое пролистывание пока не нужно. Координаты обрезаются
по viewport, без перебора filesystem и без создания элементов всех строк.

Лимиты прежние; никаких исторических копий/облаков/этапа 4. Native core/CLI
тесты и Windows type-check не заменяют Windows GPUI runtime smoke/screenshots.

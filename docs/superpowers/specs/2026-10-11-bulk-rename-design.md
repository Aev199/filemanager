# Массовое переименование

Пакет 3 общего плана: выбрать несколько файлов/папок, задать шаблон,
увидеть все старые/новые имена и ошибки до изменения диска, затем исполнить
уже проверенные Rename планы в существующей последовательной audited очереди.
Данные файлов не копируются и не сохраняются. Новых зависимостей нет.

Шаблон: `{stem}` — имя без расширения (для папки полное имя), `{ext}` —
расширение вместе с точкой либо пустая строка, `{n}` — номер начиная с 1.
Начальный шаблон `{stem} ({n}){ext}`. Литералы сохраняются; неизвестные или
незакрытые токены отказывают, значения токенов не расширяются повторно.
Группа ограничена 1000 элементами; нумерация следует порядку предпросмотра.
Шаблон ограничен 1024 UTF-16 единицами до расчёта строк; это ограничивает
размер промежуточных имён и стоимость фонового запроса.

Предпросмотр не меняет диск. Недопустимые Windows-имена, совпавшие назначения,
существующие цели, symlink/reparse points и одновременно выбранные родитель/
потомок блокируют всю кнопку исполнения. Неизменённые имена — no-op.
Циклы/swap и case-only rename не реализуем: занятая цель отказывает.
После предпросмотра планы не пересоздаются: внешние изменения источника
или поздняя занятая цель отказывают при исполнении существующих guards.
Группа не транзакционная: успешные ранние Rename остаются, failed элементы
показываются и успешные квитанции образуют один групповой Undo.

GUI: F2 на группе либо кнопка в инспекторе; отдельное окно с шаблоном,
старым/новым именем, ошибками и кнопкой применения. Все файловые проверки
на worker, обновление предпросмотра с задержкой 200 мс и generation guard.
Во время Rename использовать общую отмену и item progress с верным названием.
Escape закрывает только предпросмотр; запущенные действия отменяются общей кнопкой.
Windows runtime проверяется в итоговой редкой сборке, не подменяется Linux-тестами.

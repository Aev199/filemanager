# Рабочий интерфейс — 11.10.2026

Основание: согласованный разбор IMG_4504.png. Сохранены GPUI, колонки, история,
сеанс и механизмы копирования/переноса. main не меняем.

## Изменения

- Текущая папка получает остаток ширины; предки 170 px, текущая минимум 280 px,
  preview 210 px. Узкая панель может показывать одну колонку вместо двух.
- Реальные ширины left/right измеряются независимо через on_prepaint; обновление
  отложено через App::defer и происходит только при изменении >=1 px.
- Ключ resizable group включает current index: GPUI size() задаёт только начальный
  размер, поэтому роли текущей папки и preview не наследуют чужую ширину.
- Sidebar 200 px, инспектор 260 px. Новый профиль начинает без инспектора;
  сохранённый preferences row не переписывается. Ctrl+I открывает сведения.
- Компактные заголовки инспектора вместо 56px иконок. Кнопки групповых действий
  и зоны переноса не требуют широкого горизонтального ряда.
- Пустой staging — строка «Файлы для переноса» с tooltip, а не большая карточка.
  Drop только откладывает; Copy/Move используют прежние обработчики.
- Нет заголовка пустых рабочих пространств; команда сохранения оставлена.
- Спокойные иконки папок и индикаторы дисков, читаемые подписи обеих тем,
  разные поверхности selected/hover/trail и левый акцент выбранной строки.
- Команды больше не обозначены второй лупой; фильтр имеет короткий placeholder
  и поясняющий tooltip. Служебные надписи зоны переноса локализованы.
- palette.rs хранит цвета/light mapping; theme.rs — GPUI проекция.
  layout.rs — чистая геометрия, используемая непосредственно renderer.

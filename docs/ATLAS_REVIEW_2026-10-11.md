# Сверка с Atlas и версии файлов — 11.10.2026

Источник: главный скриншот и 8 демо-видео с atlasfm.modhyt.org
(miller columns, tabs and panes, drop zone, fuzzy finder, filter by typing,
drag-and-drop navigation, cloud, change icons). Кадры не хранятся в репозитории.

## Версии файлов (`_v_1_6`)

Новая версия документа — новый файл: `Отчёт.docx` → `Отчёт_v_1_5.docx` →
`Отчёт_v_1_6.docx`. Модуль `core/versions.rs` читает такие имена:

- суффикс в конце имени: разделитель (`_ - . пробел`), маркер `v`, `ver`, `rev`,
  `в`, `вер` в любом регистре, необязательный разделитель, 1–4 числа через
  `_ . -`: `_v_1_6`, `_v1.6`, ` v2`, `-ver_3_0_1`, `_в1_2`, `_rev2`;
- не версии: `Server2`, `Planv2`, `фото_2024_10_11`, `Отчёт_v_1_6_final`;
- сравнение числовое (1.10 новее 1.9), имена без учёта регистра, расширение
  должно совпадать; файл без суффикса — «Исходный».

Журнал: новый файл, рядом с которым есть более ранняя версия, записывается как
«Новая версия», а не «Обнаружен». История в панели сведений собирается по всему
документу (все версии, включая удалённые) и у каждой записи указана версия.
Блок «Версии» в панели сведений перечисляет файлы-версии от новой к исходной с
датой и размером; щелчок выбирает версию. Содержимое файлов по-прежнему не
читается и не хранится.

## Что совпадает с Atlas

- Колонки Миллера с подписью папки над каждой колонкой, шеврон у папок.
- Вкладки сверху со значком папки, `+`; кнопки ← → ↑ и крошки пути.
- Разделы боковой панели: места, диски с полосой заполнения и свободным местом,
  зона переноса (Dropzone) внизу.
- Режим списка: Имя / Изменён / Тип / Размер, стрелка сортировки.
- Яркое синее выделение строки с белым текстом.

## Видео, анимации и раскладка (вторая сверка)

Восемь роликов разобраны покадрово (60 кадров/с): для каждого перехода
посчитано, сколько кадров меняется изображение.

### Анимации Atlas

| Действие | В Atlas | У нас |
|---|---|---|
| Открытие папки, новая колонка, выделение, фильтр при наборе | мгновенно (1 кадр, 17 мс) | мгновенно — совпадает |
| Палитра команд / окно поиска | фон затемняется сразу, окно проявляется и чуть смещается ~120–130 мс | было без анимации → 120 мс, проявление + сдвиг 6 px |
| Контекстное меню | ~130 мс | 130 мс проявление + сдвиг — совпадает |
| Закрытие всплывающих окон | мгновенно | мгновенно — совпадает |
| Диалоги (конфликт, подтверждение) | в роликах нет | 150 мс — оставлено |

Atlas почти не анимирует: навигация и списки меняются за один кадр, плавно
появляются только всплывающие окна. «Плавность» у нас добавлять не нужно.

## Осознанные отличия (решить отдельно)

1. **Ширина колонок.** В Atlas все колонки одинаковой ширины (~165 px), справа
   остаётся пустое место. У нас текущая папка забирает остаток ширины — это
   решение предыдущей доработки по разбору IMG_4504. Вернуть равные колонки —
   одна правка в `layout.rs`.
2. **След выделения.** В Atlas выбранная папка в каждой колонке-предке подсвечена
   тем же ярким синим. У нас предки приглушены (#24456B), чтобы с клавиатуры было
   видно, где фокус.
3. **Панель сведений.** В Atlas её нет. У нас она скрыта по умолчанию (Ctrl+I) —
   в ней история, версии и комментарии.

## Не реализовано относительно Atlas (кандидаты в план)

- Значки файлов и папок из Windows Shell (у Atlas — системные/темы значков).
- Сворачиваемые разделы боковой панели с шевронами; закладки (☆ в строке
  навигации) и цветные метки (Tags).
- Поиск папок по всему диску во всплывающем окне с путями и подсказками клавиш.
- **Панели как в Atlas (крупная задача):** окно — дерево панелей, у каждой
  свои вкладки и строка навигации; деление по горизонтали и вертикали
  (Ctrl+Shift+S / Ctrl+Alt+S), закрытие панели (Ctrl+Shift+W); перетаскивание
  вкладки в панель с синей подсветкой места; синие разделители. Требует
  перестроить модель `Browser` (сейчас вкладка содержит две панели, в Atlas —
  панель содержит вкладки) и сохранение сеанса.
- Новый файл и выбор сортировки в нижней строке.
- Окно перехода по Ctrl+K: поиск папок по всему диску с путями и подсказками.

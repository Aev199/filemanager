# Обновления Papka

## Выпуск новой версии

1. GitHub → Actions → «Windows portable EXE (manual)» → Run workflow,
   ветка `feat/native-gpui-foundation`.
2. Поля запуска:
   - **channel**: `beta` — тестовая сборка (её получают только те, у кого
     в настройках выбран канал «Все сборки»); `stable` — для всех.
   - **publish**: снять флажок, если нужна только сборка без выпуска.
   - **notes**: что нового, пункты через `;`. Пусто — берутся заголовки
     коммитов с прошлого выпуска.
3. Сборка получает версию `0.1.<номер запуска>` и публикует выпуск
   `v0.1.N` с файлами `Papka.exe`, `latest.json`, `Papka-win64.zip`.

Бета-выпуск можно сделать стабильным позже: на странице выпуска снять
отметку «Set as a pre-release».

## Как обновляется программа

- Раз в сутки (и по кнопке в «О программе») Papka запрашивает список
  выпусков GitHub через системный WinHTTP — с прокси, как в браузере.
  Нет сети — проверка молча пропускается.
- Загруженный `Papka.exe` сверяется с SHA-256 из `latest.json`.
- Работающий EXE переименовывается в `Papka.old.exe`, новый ставится на
  его место; при ошибке на любом шаге всё возвращается как было.
- Перезапуск сохраняет вкладки и панели и не выполняется во время
  копирования/переноса.
- «Вернуть предыдущую версию» меняет `Papka.exe` и `Papka.old.exe` местами.
- Локальные сборки (`-dev`) сами не проверяют обновления.

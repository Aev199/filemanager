# План доработки этапов 1–3

Цель: довести Rust + GPUI файловый менеджер до повседневной работы на Windows.
Проверка пользователем — после готового пакета, а не после каждого коммита.
Push в `feat/native-gpui-foundation` разрешён; в `main` пока не вливаем.
Сборки EXE остаются ручными и редкими. Старые содержимые документов не храним.

| Пакет | Результат и проверка | Статус |
|---|---|---|
| 1. Перенос между дисками | Copy → сравнение содержимого/потоков → Корзина исходника; отмена, фазы SQLite, сохранность при отказе | Код и локальные проверки готовы; Windows smoke ожидает |
| 2. Конфликты и очередь | Явная замена с сохранением прежнего файла в Корзине, панель задач, прогресс/отмена, диагностика частичных действий | Следующий |
| 3. Массовое переименование | Предварительный список старых/новых имён, проверка конфликтов и запрещённых имён, безопасное исполнение и Undo | Запланирован |
| 4. Предпросмотр | Просмотр PDF/Office через Windows handlers, изображения и миниатюры, ограничения памяти и фоновые запросы | Запланирован |
| 5. Интерфейс | Палитра команд, закрепление вкладок, выделение рамкой, настройки; сохранить клавиатурную навигацию и отзывчивость | Запланирован |
| 6. Итоговая проверка | Одна общая Windows-сборка, тестовые каталоги/два тома, сохранения Word/Excel/CAD, сеть, несколько окон, скриншоты | Перед готовым EXE |

Большие каталоги и недоступные диски проверяем в соответствующих пакетах.
История содержит дату/время обнаружения, учётную запись наблюдателя и вручную
заданные автор/комментарий. Точное автоматическое определение автора сохранения
не обещаем. Рекурсивный постоянный сервис при закрытом окне, USN/MFT,
цветовые метки, облака/FTP/плагины и отдельный этап 4 не являются обязательными.

## Порядок исполнения

Каждый пакет: спецификация → тесты отказов → реализация → проверки core/CLI
и Windows workspace → независимое ревью → push и обновление документации.
Готовность кода и проверку EXE отмечаем отдельно. Не включаем автоматический
replay после аварии и не выдаём наличие миниатюры за полный просмотр документа.
